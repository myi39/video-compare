# video-compare

タイムアタック動画2本をブラウザ内で並べて比較するツール。
位置合わせ（A地点）・同時再生・ABループ・スロー再生に対応。

**動画はアップロードされません** — 選んだファイルはブラウザの中だけで再生され、端末の外には一切送信されません。

## 使い方

1. 「動画 1 を選ぶ」「動画 2 を選ぶ」で比較したい動画を選ぶ（最初のダイアログで2本まとめて選択もOK）
2. 各動画の歯車から微調整ボタン（±0.01〜±1秒）で「同じ場面」（スタートの瞬間など）に合わせ、「A に設定」
3. 「Aから」— 2本がそれぞれの A 地点から同時に再生される
4. 再生ボタン — 一時停止と、止めた位置からのそのまま再開
5. 区間を繰り返し見るには、どちらかの動画で区間の終わりに移動して「B に設定」→「ループ」ON
6. 速度ボタンでスロー再生（0.25×〜）

## 動作環境

- iOS Safari / Android Chrome / PC各ブラウザ
- 動画は端末で再生できる形式であること（iPhoneの録画はそのまま使えます）
